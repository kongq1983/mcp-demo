## 1. Project Setup
本项目是agent-demo-ui端，增加1个请假功能

- 比如输入我今天要请假，大模型得到今天的日期，然后返回给界面，1个特殊码，界面根据这个特殊码，在对话框显示请假表单，然后提交的话，提交到具体的业务系统，最后能提示提交成功或提交失败

- 表单字段： 请假日期开始时间、请假结束时间、请假人、请假类型(事假、病假、其他)

- 写的代码，放在agent-demo-ui目录下
