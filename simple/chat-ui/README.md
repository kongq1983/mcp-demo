# Chat UI

这是一个基于 Vue 3 + Vite 构建的聊天前端界面，完美支持流式对话显示。

## 功能特性

- **流式渲染**: 实时显示 AI 回复，流畅的打字机体验。
- **交互表单**: 当 AI 提示请假时，自动弹出交互式请假表单。
- **响应式设计**: 适配桌面和移动端。

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

启动后，访问浏览器显示的地址（通常是 `http://localhost:5173`）。

## 与后端对接

前端默认通过 `http://localhost:8001/chat` 与后端通信。请确保 `chat-server` 已启动并运行在该端口。
