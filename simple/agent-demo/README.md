# Agent Demo

本项目是一个简单的智能助手，通过 LangChain 连接远程 MCP 服务器，提供面积计算和天气预报查询功能。

## 功能特点
- 仅支持计算面积和获取天气预报。
- 使用智谱 AI (GLM-4.7-Flash) 作为核心大模型。
- 通过 MCP (Model Context Protocol) 协议调用远程工具。

## 环境准备

1. **安装 uv**:
   确保您的系统中已安装 `uv`。如果未安装，请访问 [uv 官网](https://github.com/astral-sh/uv) 查看安装指南。

2. **配置环境变量**:
   在项目根目录下创建 `.env` 文件，并添加您的智谱 AI API Key：
   ```bash
   ZHI_PU_AI_API_KEY=您的API密钥
   ```
   您可以参考 `.env.example` 文件。

## 启动步骤

1. **安装依赖并运行**:
   在 `agent-demo` 目录下运行以下命令：
   ```bash
   uv run python main.py
   ```

2. **交互方式**:
   - 程序启动后，直接在控制台输入您的问题。
   - 例如：“计算一个半径为5的圆的面积” 或 “北京明天的天气怎么样？”
   - 输入 `exit` 或 `quit` 退出程序。

## 注意事项
- 本项目要求 MCP 服务器运行在 `http://192.168.0.8:8000/mcp`。请确保服务器已启动且网络通畅。
- 助手仅会对面积和天气相关问题做出工具调用，其他问题将根据预设提示词予以拒绝。
